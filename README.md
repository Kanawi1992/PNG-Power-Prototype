# Utility Support Portal - Demo Prototype

Concept demo by Stepwise Ventures: a white-label customer support portal and chatbot for utilities.

All names, hotlines, USSD codes and email addresses are sample placeholders. Replace them with a utility's own verified information before any real use.

## Open it
1. Download the ZIP and extract it (on your phone or SD card).
2. Open `index.html` in a browser. An internet connection is needed once for styling.
